# Utility Boards

Footswitch and toggle boards that make the off-board wiring of a pedal easier.
Each board's wiki page has the schematic, PCB, BOM, and build notes.

| Board | Status | Description |
|-------|--------|-------------|
| [3PDT All Lugs](3PDT-All-Lugs) | Verified | A 3PDT footswitch board that brings all nine lugs out to a numbered row of pads, for any wiring you like. |
| [3PDT Kitchen Sink Board](3PDT-Kitchen-Sink-Board) | Verified | A 3PDT footswitch board with pads for everything: DC jack, input and output jacks, battery, LED (with its resistor) and the effect board. |
| [3PDT LED Board](3PDT-LED-Board) | Verified | A 3PDT footswitch board with the status LED, its resistor and a brightness trimmer on the board. |
| [3PDT Utility Board](3PDT-Utility-Board) | Verified | A small true bypass 3PDT footswitch board with JI / In / Gnd / Sw / Out / JO pads. |
| [4PDT Order Switcher](4PDT-Order-Switcher) | Not verified (wiring verified on the Twosome) | A toggle switch board that swaps the order of two effects (S1 then S2, or S2 then S1), with a bicolor LED that shows which order is selected. |
