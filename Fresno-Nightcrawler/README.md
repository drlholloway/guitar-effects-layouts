# Fresno Nightcrawler
### Verified

A PCB and faceplate for Christine by The Tone God, an oscillating glitch fuzz built on a CD4049 hex inverter in linear mode, with Volume, Tone, Gain, Oscillator Freq and Power Starve controls. 125B enclosure.

**Schematic, PCB, BOM, and build notes are on the wiki: [Fresno Nightcrawler](https://github.com/drlholloway/guitar-effects-layouts/wiki/Fresno-Nightcrawler)**
