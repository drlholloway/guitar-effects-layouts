# Proteus
### Verified

A PCB and faceplate based on MicTester's Si Tone Bender (Fuzz Dog's [PitBull](https://shop.pedalparts.co.uk/product/pitbull)), a four 2N5088 fuzz: a boost into a Fuzz Face pair with Girth, Bias and Volts controls and a blended tone control. 125B enclosure.

**Schematic, PCB, faceplate, BOM, and build notes are on the wiki: [Proteus](https://github.com/drlholloway/guitar-effects-layouts/wiki/Proteus)**
