# Biggus Dickus
### Verified

A PCB and faceplate for [Chuck D. Bones'](https://forum.pedalpcb.com/threads/another-dirt-pedal.4405/) Biggus Dickus circuit, with a bias trimmer and eyes that light up as you play. 125B enclosure.

**Schematic, PCB, faceplate, BOM, and build notes are on the wiki: [Biggus Dickus](https://github.com/drlholloway/guitar-effects-layouts/wiki/Biggus-Dickus)**
