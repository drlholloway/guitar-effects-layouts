# Supreme Fart Machine
### Verified

A PCB and faceplate for Chuck D. Bones' [Supreme Fart Machine](https://forum.pedalpcb.com/threads/this-week-on-the-breadboard-the-ehx-ripped-speaker.30266/), his reworking of the EHX Ripped Speaker: a three transistor fuzz with a Rip control that gates it from splatty to wide open, a Big Muff style tone control and a MOSFET output buffer. 125B enclosure.

**Schematic, PCB, faceplate, BOM, and build notes are on the wiki: [Supreme Fart Machine](https://github.com/drlholloway/guitar-effects-layouts/wiki/Supreme-Fart-Machine)**
