# guitar-effects-layouts
Guitar Effect Pedal Layouts that I've made for sharing with everyone.

1. [**The Everlasting Tantrum v2**](The-Everlasting-Tantrum/README.md) - My take on an unreleased DOD and Devi Ever collaboration with some fun modifications.
2. [**Biggus Dickus**](Biggus-Dickus/README.md) - A PCB and faceplate for Chuck D. Bones' Biggus Dickus circuit, with a bias trimmer and eyes that light up as you play.
3. [**Ground Fault**](Ground-Fault/README.md) - A PCB of Fuzzhugger FX's long out of production Arc Flash, made from a trace on PedalPCB. **The current layout is incorrect and needs to be updated.**
