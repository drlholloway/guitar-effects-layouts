# Hodag
### Verified

A PCB and faceplate based on the Maestro FZ-1B Fuzz-Tone (version 2): four NPN transistors, with Volume and a Texture control that blends the first gain stage with the fuzz pair. A fairly quiet circuit. 125B enclosure.

**Schematic, PCB, faceplate, BOM, and build notes are on the wiki: [Hodag](https://github.com/drlholloway/guitar-effects-layouts/wiki/Hodag)**
